# 튜토리얼 보스 — 사이드뷰

`TutorialBoss` 하나를 부착합니다. Internal의 partial 스크립트는 추가로 붙이지 않습니다.
기존 Animator의 Idle / Move / Slam / Shockwave / Stagger와 스프라이트는 그대로 사용합니다.

## 이동과 공격

- 플레이어 모드와 관계없이 좌우 추적 + 중력을 사용합니다. 벽과 낭떠러지 앞에서 멈춥니다. 발판 간 자동 점프는 하지 않습니다.
- 근접 공격은 좌우 반전되는 Melee Hit Offset / Size 사각형이며 Slam Hit Frame에서 피해와 패링을 판정합니다. 높은 발판의 플레이어에게 허공 공격을 반복하지 않습니다.
- 충격파는 항상 좌우 2개입니다. 패링 후에도 수평으로 돌아갑니다. Origin Offset / Radius / Visual Scale / Speed / Distance를 조절할 수 있습니다.
- 낙석은 Side View Ground Layers에 포함된 실제 바닥/발판 위로 떨어집니다. 방 범위 안에 바닥 윗면이 들어 있어야 합니다.
- 패턴 오류, 거대화 시 발 고정, N회 패링 경직, 반사 효과는 유지합니다.

## 방과 문 설정

1. 보스와 별개인 빈 오브젝트에 BoxCollider2D를 넣고 Is Trigger를 켭니다. 보스 방 전체를 감싸도록 크기를 지정합니다. 사이드뷰 방은 회전 없이 배치하는 것을 권장합니다.
2. 보스의 **Room Area**에 연결합니다. 비워 두면 최초 보스 위치 + **Room Offset / Room Size**가 방 범위가 됩니다. 보스가 걸어도 방은 따라가지 않습니다.
3. **Lock Room On Entry**를 켭니다(기본 ON).
4. **Room Gates**가 비어 있으면 플레이 중 방 좌우 경계에 임시 빨간 차단벽이 생깁니다. 두께는 **Room Gate Thickness**로 조절합니다. 기즈모의 주황색 사각형을 확인하세요. 바닥/천장/상하 통로는 자동 생성하지 않으므로 맵에서 막아 주세요.
5. 직접 만든 문을 쓰려면 고정된 문 오브젝트마다 **BoxCollider2D**를 넣고 **Room Gates** 배열에 모두 연결합니다. 문 GameObject는 활성화해 두세요. Rigidbody2D, 보스 몸, Room Area를 문으로 연결하지 않습니다. 이미지가 필요하면 문 또는 자식에 SpriteRenderer를 붙입니다. 연결된 문의 콜라이더와 그림을 함께 켜고 끕니다.
6. 플레이어가 방 안으로 완전히 들어와 문과 겹치지 않으면 닫힙니다. 보스 처치 시 모두 열립니다. 단순히 플레이어 중심이 방 밖으로 나갔다고 문이 열리지는 않습니다.

문은 일반 비 Trigger 콜라이더입니다. **플레이어의 이동 충돌 마스크 및 Physics 2D 레이어 충돌 설정에 문 레이어가 포함**되어야 합니다. 자동 문은 Default 레이어를 사용합니다. 수동 문은 모든 출입구를 직접 지정해야 합니다.

## 재시작 / 안전 처리

- 레이저 즉사 등 `PlayerMove.NotifyHazardTeleport()`가 호출되는 재시작/워프 시 문을 열고 보스 체력·패링 누적·공격을 초기화합니다. 재입장하면 다시 닫힙니다. 문 밖에서 리스폰한 플레이어가 재입장하지 못하는 문제를 방지합니다.
- 보스를 비활성화하거나 제거하면 문이 열립니다. 자동 생성 문은 보스 제거 시 함께 정리합니다.
- 씬/프리팹의 기존 그림, 위치, Room Size 값은 변경하지 않습니다. 기존 프리팹을 배치한 뒤 실제 보스 방 크기에 맞게 Room Area 또는 Room Offset / Size를 조절하세요.
