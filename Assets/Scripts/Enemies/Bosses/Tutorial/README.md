# 튜토리얼 보스 — 사이드뷰

`TutorialBoss` 하나를 부착합니다. Internal의 partial 스크립트는 추가로 붙이지 않습니다.
기존 Animator의 Idle / Move / Slam / Shockwave / Stagger와 스프라이트는 그대로 사용합니다.
보스는 사이드뷰 전용입니다. 이전 탑다운 XY 낙석 배치/원형 경고 분기, 모드 분기, 사용하지 않는 Melee Range / Stopping Distance 필드는 제거했습니다. 공용 몬스터 이동/투사체 코드는 다른 몬스터에서도 사용하므로 유지합니다.

## 낙석 개수와 배치

- **Rockfall Count**: 한 회차 최대 개수(1~16). 현재 SideViewTest 씬의 값은 4이며 Inspector에서 변경합니다.
- **Rockfall Area**: 별도 낙석 범위입니다. 비우면 Room Area 또는 Room Offset / Size 범위 전체를 사용합니다.
- 방의 가로 구간을 탐색하여 **Side View Ground Layers**에 해당하는 실제 바닥 위로 분산 배치합니다. 상단의 배치 불가능한 표면을 만나도 아래 바닥 탐색을 계속합니다.
- **Rockfall Target Player**는 첫 돌 하나를 플레이어 아래에 배치하고, 나머지는 떨어진 위치부터 채웁니다. 경고 이후 위치는 고정됩니다.
- 공간이 충분하면 Count까지 생성합니다. 바닥 없음, 벽, 좁은 범위, 큰 반지름/거대화로 안전 간격이 부족하면 최대 개수보다 줄어듭니다. 개수를 맞추기 위해 벽 안이나 방 밖에 강제로 생성하지 않습니다.
- **Rockfall Stagger**가 0이면 동시 낙하, 양수면 설정 간격으로 순차 낙하합니다. 모든 착지 경고는 회차 시작 시 표시됩니다.

## 이동과 공격

- 근접/충격파는 준비부터 공격 클립이 끝날 때까지 제자리에서 진행합니다. 타격 후 남은 애니메이션과 2페이즈의 별도 충격파 준비 중에도 추적하지 않습니다. 중력과 바닥 착지는 유지합니다.
- 공격 사이와 낙석 맵 패턴만 진행 중일 때는 추적 이동을 계속합니다. 이미 발사된 충격파가 남아 있어도 공격 동작이 끝나면 다시 추적합니다. 실제 근접 박스, 벽·낭떠러지, 누적 패링 경직, 사망은 이동을 막습니다. 공격 시작 방향은 타격 도중 뒤집지 않고 유지합니다.
- **Melee Hit Offset / Melee Hit Size**의 청록색 박스에 플레이어 몸이 겹치고 시야가 확보되면 근접 공격을 선택합니다. 범위 밖이면 충격파를 선택합니다. 예전 Melee Range / Stopping Distance와 원형 기즈모는 더 이상 사용하지 않습니다.
- 충격파는 Enable Shockwave / First Delay / Interval을 유지합니다. 쿨타임 중에는 추격하며, 범위 안에 들어오면 충격파보다 근접을 우선합니다. 이미 준비를 시작한 공격은 거리 변화만으로 취소하지 않습니다.
- 낙석은 독립 시간표로 동작하여 근접/충격파와 함께 진행됩니다. 2페이즈에서는 근접 동작 도중 플레이어가 근접 범위 밖에 있고 충격파 시간이 되면 별도 준비 시간 후 좌우 충격파를 발사합니다. 근접 애니메이션을 끊지 않습니다. 일반 충격파는 기존 Shockwave 애니메이션을 사용합니다.
- 보스 UI는 체력·페이즈·패링 게이지와 별도 충격파 준비 시간만 표시합니다. 오류 이름·오류 조합·반사 남은 시간은 표시하지 않습니다. 오류 효과 자체와 플레이어의 획득/보관함 표시는 유지합니다.

## 페이즈 / 복합 오류

- **Second Phase Health Ratio**: 기본 `0.5`. HP 50% 초과는 1페이즈, 50% 이하는 2페이즈입니다. 회복/재시작으로 HP가 올라가면 다시 해당 체력의 페이즈가 됩니다.
- **Second Phase Error Count**: 기본 `2`, 최대 `3`. 1페이즈는 패턴당 오류 1종, 2페이즈는 서로 다른 오류 2~3종을 조합합니다. Pattern Error Chance(오류 적용 확률)와 Allow 설정은 유지합니다. 허용한 종류가 부족하면 그 수만큼만 적용합니다.
- 페이즈 변경은 새로 시작하는 패턴부터 반영됩니다. 진행 중인 돌/충격파/근접 회차의 구성은 갑자기 바뀌지 않습니다.
- 거대화+가속은 크기와 속도를 함께 변경합니다. 반사는 다른 오류와 동시에 유지되며 지속 시간이 끝나도 같은 패턴의 거대화/가속은 남습니다.
- 해당 회차를 패링하면 남아 있는 오류를 전부 해제하고 각 종류를 한 번씩 지급합니다. 보관함은 여전히 2칸이며 초과 보상은 기존 교체 UI/시간 제한 규칙을 사용합니다. 같은 회차의 여러 돌/충격파를 패링해도 중복 지급하지 않습니다.
- 동시 반사 오류가 여러 개 있어도 받은 피해를 중복 반사하지 않고 가장 높은 반사 배율 한 번만 사용합니다.

- 플레이어 모드와 관계없이 좌우 추적 + 중력을 사용합니다. 벽과 낭떠러지 앞에서 멈춥니다. 발판 간 자동 점프는 하지 않습니다.
- 근접 공격은 좌우 반전되는 Melee Hit Offset / Size 사각형이며 Slam Hit Frame에서 피해와 패링을 판정합니다. 높은 발판의 플레이어에게 허공 공격을 반복하지 않습니다.
- 충격파는 항상 좌우 2개입니다. 패링 후에도 수평으로 돌아갑니다. Origin Offset / Radius / Visual Scale / Speed / Distance를 조절할 수 있습니다.
- 낙석은 Side View Ground Layers에 포함된 실제 바닥/발판 위로 떨어집니다. 방 범위 안에 바닥 윗면이 들어 있어야 합니다.
- 패턴 오류, 거대화 시 발 고정, N회 패링 경직, 반사 효과는 유지합니다.

## 방과 문 설정

1. 보스와 별개인 빈 오브젝트에 BoxCollider2D를 넣고 Is Trigger를 켭니다. 보스 방 전체를 감싸도록 크기를 지정합니다. 사이드뷰 방은 회전 없이 배치하는 것을 권장합니다.
2. 보스의 **Room Area**에 연결합니다. 비워 두면 최초 보스 위치 + **Room Offset / Room Size**가 방 범위가 됩니다. 보스가 걸어도 방은 따라가지 않습니다.
3. **Lock Room On Entry**를 켭니다(기본 ON).
4. **Room Gates**가 비어 있으면 플레이 중 방 좌우 경계에 임시 빨간 차단벽이 생깁니다. 두께는 **Room Gate Thickness**로 조절합니다. 기즈모의 주황색 사각형을 확인하세요. 바닥/천장/상하 통로는 자동 생성하지 않으므로 맵에서 막아 주세요.
5. 직접 만든 문을 쓰려면 고정된 문 오브젝트마다 **BoxCollider2D**를 넣고 **Room Gates** 배열에 모두 연결합니다. 문 GameObject는 활성화해 두세요. Rigidbody2D, 보스 몸, Room Area를 문으로 연결하지 않습니다. 이미지가 필요하면 문 또는 자식에 SpriteRenderer를 붙입니다. 연결된 문의 콜라이더와 그림을 함께 켜고 끕니다.
6. 플레이어가 방 안으로 완전히 들어와 문과 겹치지 않으면 닫힙니다. 보스 처치 시 모두 열립니다. 단순히 플레이어 중심이 방 밖으로 나갔다고 문이 열리지는 않습니다.

문은 일반 비 Trigger 콜라이더입니다. **플레이어의 이동 충돌 마스크 및 Physics 2D 레이어 충돌 설정에 문 레이어가 포함**되어야 합니다. 자동 문은 Default 레이어를 사용합니다. 수동 문은 모든 출입구를 직접 지정해야 합니다.

## 재시작 / 안전 처리

- 레이저 즉사 등 `PlayerMove.NotifyHazardTeleport()`가 호출되는 재시작/워프 시 문을 열고 보스 체력·패링 누적·공격을 초기화합니다. 재입장하면 다시 닫힙니다. 문 밖에서 리스폰한 플레이어가 재입장하지 못하는 문제를 방지합니다.
- 보스를 비활성화하거나 제거하면 문이 열립니다. 자동 생성 문은 보스 제거 시 함께 정리합니다.
- 씬/프리팹의 기존 그림, 위치, Room Size 값은 변경하지 않습니다. 기존 프리팹을 배치한 뒤 실제 보스 방 크기에 맞게 Room Area 또는 Room Offset / Size를 조절하세요.
