# 기존 웨이브 구역 정리
사이드뷰 일반 몬스터를 직접 배치하는 구조로 전환하면서 CombatAreaLock 및 일반 몬스터 스포너/웨이브 설정 도구를 제거했습니다.

REDACT 씬에 있던 해당 제어 컴포넌트와 스포너 프리팹 인스턴스 연결도 제거했습니다. 기존 웨이브 장벽 GameObject는 비활성 상태로 남기고 구역 감지 Collider도 껐습니다. 더 이상 입장/처치 수에 따라 문을 잠그지 않습니다.

맵 자체, 보스, 플레이어와 튜토리얼 기능은 삭제하지 않았습니다. 빈 구역/Spawn Point는 배치 참고용으로 남을 수 있습니다.
