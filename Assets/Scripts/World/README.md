# 월드 상호작용

## V 포탈 — 같은 씬 안에서 위치 이동

1. Play 종료 후 Hierarchy 우클릭 → **Story → Portal**. `Portal`과 `Portal Destination`이 생성되고 연결됩니다.
2. Portal을 입구에 배치하고, Portal Destination을 이동할 곳으로 옮깁니다. 목적지는 플레이어 Transform 중심이 놓일 곳이므로 몸이 바닥/벽에 묻히지 않도록 높이도 맞추세요.
3. **Interaction Offset / Interaction Size**로 사용 가능한 사각형을 조절합니다. 선택 시 보라색 기즈모와 목적지 연결선이 표시됩니다.
4. 포탈 그림은 원하면 Portal 오브젝트에 SpriteRenderer를 추가해 직접 넣으세요. 감지용 Collider나 Rigidbody는 필요 없습니다.
5. Play 중 범위 안에서 **V를 한 번** 누르면 이동합니다. Show Prompt / Prompt Offset으로 안내 표시를 조절합니다.

- 수동 설정도 가능합니다. 빈 오브젝트에 **Portal**을 붙이고 **Destination**에 목적지 Transform을 연결하세요. 다른 씬을 불러오는 기능은 아닙니다.
- 양방향 이동은 반대편에도 Portal을 하나 배치하고 각 Destination을 반대편 도착 지점에 연결하세요. 범위가 겹치면 가장 가까운 유효 포탈 하나만 사용합니다.
- 키 유지로 반복 이동하지 않으며 이동 직후 0.25초 동안 재사용을 막습니다. 범위 밖/목적지 미지정/포탈 비활성 상태에서는 사용할 수 없습니다.
- HP·대시/가드 자원·보관 오류·체크포인트는 유지합니다. 잡은 물체를 놓고 공격·가드·패링·대시·점프 속도와 편집/Paste 준비를 정리합니다. 오류 교체 선택 또는 도감 중에는 사용할 수 없습니다.
- 목적지의 CameraBoundsArea가 있으면 기존 카메라 페이드를 사용합니다. 같은 방 안에서는 추적 지연을 초기화합니다. 목적지에 바운드가 없으면 출발 방의 경계에 갇히지 않습니다.
- 레이저/튜토리얼이 출발지와 목적지 사이의 공간을 실제로 지나간 것으로 처리하지 않도록 워프를 알립니다. 목적지 자체에 레이저가 있으면 피해를 받을 수 있습니다. 안전한 위치를 지정하세요.
- 튜토리얼 보스 방이 잠겨 있으면 그 방으로 들어가거나 나가는 포탈 사용을 막습니다. 보스 처치 후 다시 사용할 수 있습니다.
- `PlayerMove.Portal.cs`는 플레이어의 partial 구현, `PortalSetup.cs`는 Editor 도구이므로 직접 부착하지 않습니다.

## 기존 웨이브 구역 정리
사이드뷰 일반 몬스터를 직접 배치하는 구조로 전환하면서 CombatAreaLock 및 일반 몬스터 스포너/웨이브 설정 도구를 제거했습니다.

REDACT 씬에 있던 해당 제어 컴포넌트와 스포너 프리팹 인스턴스 연결도 제거했습니다. 기존 웨이브 장벽 GameObject는 비활성 상태로 남기고 구역 감지 Collider도 껐습니다. 더 이상 입장/처치 수에 따라 문을 잠그지 않습니다.

맵 자체, 보스, 플레이어와 튜토리얼 기능은 삭제하지 않았습니다. 빈 구역/Spawn Point는 배치 참고용으로 남을 수 있습니다.
