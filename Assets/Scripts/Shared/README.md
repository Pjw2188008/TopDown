# 여러 기능이 사용하는 공용 코드

## Attachable — 공용 피격 연출
- DamageBlink.cs: 실제 HP가 감소하면 몸 스프라이트를 약 0.35초 빨간색으로 표시합니다. 피해 처리 코드가 첫 피격 시 자동 추가합니다. 기존 파일명/GUID는 유지합니다.
- 미리 플레이어/몬스터 루트에 붙이면 Duration(기본 0.35초), Hit Color(기본 빨간색), 대상 Renderer를 Inspector에서 조절할 수 있습니다. Blink Interval은 더 이상 사용하지 않습니다.
- 연속 피격 시 시간을 갱신합니다. 종료/비활성화 시 원래 색상으로 복구합니다.
- 캐릭터를 숨기지 않으며 투명도/애니메이션/Collider는 변경하지 않습니다. 피격 표시 중 가속·반사 오류가 적용/해제되면 종료 후 최신 기본 색상을 사용합니다.
- 무적 효과가 아닙니다. 패링·전량 반사·100% 피해 감소 등으로 HP가 줄지 않으면 피격 색상을 표시하지 않습니다. 사망 제거 타이밍도 바꾸지 않습니다.

## Internal — 직접 부착하지 않음
- CombatDamage.cs: 피해 수신 인터페이스와 대상 탐색·피해 전달.
- AttackMath.cs: 4방향 공격 판정과 끝에서 세 번째 프레임 시점 계산.
- InteractionMotion.cs: 플레이어·몬스터·상호작용 물체가 재사용하는 충돌 이동 거리 계산.
- SpriteTint.cs: 기본 색상과 임시 피격 색상을 분리합니다. 오류 효과는 GetColor/SetColor로 기본 색을 다루므로 피격 색상이 영구적으로 저장되지 않습니다.

Internal은 직접 부착하지 않는 공용 규칙과 표시 상태 관리 코드입니다.
