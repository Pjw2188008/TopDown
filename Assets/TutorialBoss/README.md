# 튜토리얼 보스 — 기본 패턴 프로토타입

`TutorialBoss.prefab`을 씬에 넣으세요. 또는 `Tools > Story > Tutorial Boss > Create Boss In Scene`을 사용합니다. 기존 씬에는 자동 배치하지 않습니다. 일반 근접/원거리 적 스크립트를 함께 붙이지 마세요.

## 기본 규칙

- 같은 씬의 플레이어가 **사이드뷰 ON / 2.5D OFF**이면 2D 대응을 자동 사용합니다. 좌우로 추적하고 중력으로 바닥에 서며 벽/낭떠러지 앞에서 멈춥니다. 자동 점프는 하지 않습니다. 아래의 네 갈래 설명은 탑다운 기준이며, 사이드뷰에서는 **좌우 두 갈래**만 생성합니다(Shockwave Angle 무시). 패링 귀환도 수평이며 일반 원거리 탄환의 조준은 바꾸지 않습니다.
- 사이드뷰 낙석은 `Side View Ground Layers`에 속한 일반 Collider2D 윗면을 찾아 떨어집니다. `Room Area / Rockfall Area`에 바닥까지 포함하세요. 플레이어 표적은 발 아래 표면, 무작위 표적은 선택된 X 위치의 가장 위쪽 표면을 사용합니다. 바닥이 없거나 범위가 좁으면 생성 수가 줄어듭니다. 경고는 얇은 가로 표시이며 거대화 시 그림/판정/발밑 높이를 함께 보정합니다. 평평한 발판용이며 가파른 경사는 제외합니다.

- 플레이어가 방에 들어오면 추적하며 근접 범위에서 휘두릅니다. 원거리 투사체 공격은 제거했고, **거리와 관계없이 주기적으로 낙석 맵 패턴**을 사용합니다. 낙석 중에도 추적하며 근접/충격파를 사용합니다. 보스 자신의 공격 준비/재생/후딜 애니메이션 및 경직 중에는 이동하지 않습니다.
- Melee Range(2.5) 안: 플레이어를 향해 공격 방향 고정 → Slam 애니메이션 재생 → **설정한 타격 프레임에 보스 앞쪽에서 피해/패링 판정을 한 번 실행** → 후딜 애니메이션까지 재생 → 쿨다운. 별도 근접 이펙트는 생성하지 않습니다. 휘두르는 동작을 보고 타격 직전에 우클릭하여 가드를 유지하세요.
- Melee Range 밖에서는 접근합니다. 낙석 시간이 되면 근접 범위 안/밖 모두 같은 맵 패턴을 사용합니다. 보스와 플레이어 사이의 벽은 근접 시작을 막지만 낙석 주기는 막지 않습니다.
- 낙석은 독립 시간표로 시작하고 끝납니다. 근접/충격파 애니메이션과 쿨다운을 변경하지 않으며, 두 동작 중 하나와 낙석이 동시에 진행될 수 있습니다. 근접과 충격파 동작끼리는 기존처럼 순서대로 사용합니다.
- 근접 공격에는 별도 이펙트/경고가 없습니다. 낙석에는 바닥 경고 원과 떨어지는 돌이 표시됩니다.

## 맵 패턴 1 — 낙석

별도 컴포넌트 부착 없이 기존 `TutorialBoss`에서 동작합니다. Inspector의 **맵 패턴 1 / 낙석**에서 설정하세요.

- `Rockfall First Delay`: 방 입장 후 첫 패턴까지 3초. 진행 중인 공격을 기다리거나 끊지 않고 낙석을 별도로 시작합니다.
- `Rockfall Interval`: 패턴 종료 후 다음 패턴까지 최소 6초(게임 시간). 방 밖에서는 초기 대기로 되돌아가며 경직 중에는 진행하지 않습니다.
- `Rockfall Count`: 최대 5곳(1~16). 공간이 부족하면 개수가 줄고, 한 곳도 배치할 수 없으면 이번 패턴을 건너뜁니다.
- `Rockfall Area`: 선택 사항. 고정된 방 안에 BoxCollider2D를 두고 Is Trigger를 켠 뒤 연결하면 낙석 범위를 직접 조절할 수 있습니다. 미지정 시 Room Area, 그것도 없으면 Room Size/Offset을 사용합니다. 주황색 기즈모로 전용 범위를 표시합니다.
- `Rockfall Target Player`: 기본 ON. 한 곳은 패턴 시작 당시 플레이어 위치, 나머지는 무작위 위치입니다. 벽/경계에 걸리는 위치는 대체합니다. 표시된 경고는 플레이어를 따라오지 않습니다.
- `Rockfall Warning Time`: 경고 1초, `Rockfall Fall Time`: 낙하 0.35초. `Rockfall Stagger`: 돌마다 0.15초씩 순차 낙하(0이면 동시). 모든 경고는 시작부터 표시합니다.
- `Rockfall Height`: 시각적 낙하 높이 4. `Rockfall Radius`: 경고/착지 판정 반지름 0.65. 돌이 공중에 있을 때는 충돌하지 않고, 착지 순간 그 원 안에 있는 플레이어에게 돌당 1회 피해를 줍니다.
- `Rockfall Damage`: 피해 2. **착지 직전 우클릭을 시작하고 유지하면 패링**합니다. 성공 시 피해/가드 게이지 소모 없이 보스 패링 횟수를 올리며 돌이 잠깐 청록색으로 표시됩니다. 낙석을 새 투사체로 돌려보내지는 않습니다. 일반 가드/반사 피해 처리는 유지합니다. 피해가 0이면 패링도 판정하지 않습니다.
- `Rockfall Parry Window`: 낙석의 최소 패링 허용 시간, 기본 0.3초입니다. 공중에서 미리 판정하거나 착지 이후 소급 성공하지 않습니다. 너무 일찍 우클릭하면 일반 가드이고, 돌을 피하면 피해/패링 모두 발생하지 않습니다.
- `Rockfall Sprite`: 돌 이미지. 비우면 회색 사각형을 사용합니다. `Rockfall Sorting Layer / Order`로 맵 앞에 보이도록 조절할 수 있습니다(기본 보스 레이어 / 25).
- 방 경계와 Blocking Layers의 일반 벽 콜라이더를 피하고, 경고끼리 겹치지 않게 배치합니다. 바닥 전체에 일반 콜라이더가 있다면 해당 레이어를 Blocking Layers에서 제외하세요.
- 방 이탈, 대상 비활성화, 보스 경직/사망/비활성화 시 남은 경고와 돌을 즉시 숨기고 정리합니다. 낙석은 보스를 Idle로 전환하지 않으며 현재의 추적/근접/충격파 동작을 유지합니다.

## 근접 휘두르기 설정

- 현재 보스 원본은 **왼쪽을 바라보는 에셋**입니다. 스크립트 기본값과 프리팹의 `Move Sprite Faces Right`는 OFF입니다. 양수 Scale 기준 왼쪽 이동/공격은 Flip X OFF, 오른쪽은 ON이며 공격 사각형도 같은 방향으로 반전합니다. 기존 씬에서 이 항목을 직접 ON으로 저장했거나 열린 에디터에 이전 값이 남아 있으면 해당 보스에서도 OFF로 맞추세요.
- `Melee Hit Offset`(기본 X=1.4, Y=0): 오른쪽을 바라볼 때 보스 중심 기준 공격 사각형의 위치입니다. X/Y 모두 음수도 입력할 수 있습니다. 왼쪽을 바라보면 X만 자동 반전하고 Y는 유지합니다.
- `Melee Hit Size`(기본 X=2.2, Y=2.2): 실제 타격 사각형의 가로/세로입니다. Offset/Size는 월드 단위이며 루트 Scale과 별도로 조절합니다. 0 이하 크기는 판정에서 0.01로 제한합니다. 기존 원형 Radius 설정을 대체합니다.
- Scene의 Gizmos를 켜고 보스를 선택한 뒤 Offset/Size를 조절하세요. **청록색 사각형이 실제 공격 판정**입니다. 노란 원은 패턴을 선택하는 거리인 `Melee Range`로, 실제 타격 범위가 아닙니다. 추가 BoxCollider2D나 자식 오브젝트는 필요 없습니다.
- `Move Sprite Faces Right`는 **Flip X를 끈 원본 그림**의 방향입니다. 원본이 왼쪽을 보면 OFF, 오른쪽이면 ON으로 설정하세요. 그림 내용을 코드가 자동 인식하지는 않습니다. SpriteRenderer의 Flip X 및 좌우 음수 Scale을 반영해 편집 모드에서도 사각형을 같은 쪽에 표시합니다.
- 공격 시작 시 방향이 고정되므로 플레이어가 뒤로 피하면 판정이 따라가지 않습니다. 타격 순간 실제 플레이어 콜라이더가 범위 안에 있고 벽에 가려지지 않아야 맞습니다. 몸 전체에 상시 공격 판정을 주지 않습니다.
- 기존 `Boss_Slam` 클립과 `Slam` 상태 이름을 유지했습니다. Ctrl+6에서 **Boss_Slam의 Sprite 트랙**에 새 휘두르기 프레임을 넣으세요. 기존 이미지/클립은 삭제하거나 덮어쓰지 않았으므로 교체 전에는 기존 동작이 재생됩니다.
- `Slam Hit Frame`(기본 11)을 새 이미지가 실제로 타격하는 프레임에 맞추세요. 공격 프레임에서 피해와 패링을 함께 검사하며 별도 Animation Event는 필요 없습니다.
- 공격 시작 시 좌우 방향에 맞춰 반전하고 공격 중에는 유지합니다. 사각형도 보스의 좌우 방향을 따르며, 위/아래/대각선으로 자동 회전하지 않습니다. 상하 타격 범위는 Offset Y와 Size Y로 조절하세요.
- 벽에 가려진 플레이어에게 새 근접 공격을 시작하지 않습니다. Blocking Layers에 벽 레이어를 포함하세요.
- 보스 몸은 피격용 Trigger입니다. 플레이어와 밀지 않으며 몸에 닿았다는 이유만으로 피해를 주지 않습니다.

## 방 범위와 추적 설정

1. 고정된 방 오브젝트에 `BoxCollider2D`를 두고 `Is Trigger`를 켭니다. 기존 CombatAreaLock의 입장 범위를 그대로 연결해도 됩니다.
2. 보스의 `Room Area`에 그 콜라이더를 넣으세요. 보스 자신의 콜라이더나 보스 자식은 연결하지 마세요. 방의 Size/Offset을 직접 조절합니다.
3. 미지정 상태에서는 보스 최초 위치 기준 `Room Size`(기본 24×16), `Room Offset` 사각 범위를 사용합니다. 보스 선택 시 파란색 기즈모로 확인하며, 추적 중에도 범위 중심은 움직이지 않습니다. 실제 방 크기에 맞춰 설정하세요.
4. `Chase Speed`는 추적 속도(기본 2), `Stopping Distance`는 접근 후 멈출 거리(기본 1.8)입니다. 멈춤 거리는 근접 범위의 90% 이하로 제한합니다.
5. `Blocking Layers`에 벽/장애물 레이어를 넣으세요. 기존 몬스터 길찾기로 우회하며, 보스 Trigger 피격 콜라이더 크기로 벽을 검사합니다. 다른 몬스터의 충돌 처리 방식은 변경하지 않습니다.

- 방 안에 있는 동안만 추적/공격합니다. 방 밖으로 나가면 준비 중인 근접 공격과 낙석을 취소하며, 재입장하면 다시 시작합니다. HP와 패링 누적은 유지합니다. 방 안으로 리스폰한 경우에는 방 이탈로 판정되지 않습니다.
- 보스는 지정된 방 안에 배치하세요. 이동 후보의 중심이 방 밖이면 이동하지 않습니다. 실제 벽에는 일반 Collider2D가 필요합니다.
- 이번 작업은 씬의 방 배치나 문 잠금 이벤트를 자동 변경하지 않습니다. Room Area 연결은 방 감지에만 사용하며, 문 잠금/전멸 처리는 기존 CombatAreaLock이 담당합니다.
- 실제 추적 이동 중에는 `Move`(Boss_Move), 정지하면 `Idle`을 재생합니다. 벽에 막혀 이동하지 못할 때도 Idle입니다. 공격/경직/후딜을 Move가 끊지 않으며 11번째 프레임 패링은 그대로입니다.

## 보스 이동 애니메이션 프레임 넣기

1. 씬/프리팹의 보스 루트 `TutorialBoss`를 선택하고 **Ctrl+6**을 누릅니다.
2. Animation 창에서 **Boss_Move**를 선택합니다. 루트 `Sprite Renderer → Sprite` 트랙에 이동 스프라이트 프레임을 넣으세요. 클립은 Loop Time을 켠 상태로 준비했습니다.
3. 현재 이동용 이미지가 없어 기존 보스 이미지가 들어 있는 임시 클립입니다. 프레임을 교체하면 걷는 동작이 나타납니다. 별도 Body/Visual 자식은 필요 없습니다.
4. `Flip Sprite With Movement`를 켜면 좌우 이동 방향에 따라 반전합니다. 오른쪽을 향한 원본은 `Move Sprite Faces Right` ON, 왼쪽 원본은 OFF로 두세요.

`Tools > Story > Tutorial Boss > Configure Movement Animation`으로 Move 연결만 다시 준비할 수 있습니다. 기존 이동 프레임, 공격 클립, 상태 연결, 프리팹은 보존합니다. 별도 전이/Trigger는 필요 없으며 스크립트가 실제 이동량으로 재생 상태를 선택합니다.

## 네 갈래 충격파

- 기본은 보스 중심에서 **상하좌우(+) 네 방향에 동시에 1개씩** 발사합니다. 가까이 있어도 사용할 수 있으며 진행 중인 근접 동작을 끊지 않습니다. 낙석과는 동시에 사용할 수 있습니다.
- `Enable Shockwave`로 사용 여부, `Shockwave First Delay`(5초)로 첫 대기, `Shockwave Interval`(9초)로 공격 시작 사이 최소 간격을 조절합니다. 편집 모드 슬로모션/일시 정지를 따릅니다.
- `Shockwave Windup Time`(1초)이 지나 애니메이션의 `Shockwave Release Frame`(9번째 프레임)에 도달하면 발사합니다. 실제 프레임 번호는 첫 프레임을 1로 셉니다. Animation Event를 넣을 필요 없습니다. 발사 후에도 애니메이션 끝까지 재생하고 기존 Attack Cooldown만큼 쉽니다.
- `Shockwave Speed`(5), `Distance`(10), `Radius`(0.35), `Damage`(2)로 이동 속도·최대 거리·원형 타격 반지름·피해량을 조절합니다. `Origin Offset`은 발사 중심 위치이며 좌우 플립과 무관합니다. `Angle`은 0이면 +, 45이면 X입니다.
- 보스 선택 시 하늘색 선 네 개가 발사 방향/최대 거리, 원은 충격파 타격 반지름을 보여 줍니다. 방 경계/벽에 닿으면 최대 거리보다 일찍 사라집니다.
- `Shockwave Effect Prefab`에 이펙트 프리팹을 지정할 수 있습니다. 비우면 `Assets/Resources/TutorialBossEffects/ShockwaveEffect.prefab`을 자동 사용합니다. 해당 리소스도 없을 때만 기존 Shockwave Sprite/원형 임시 그림으로 대체합니다. 애니메이션 사용 시 Sprite는 이펙트 클립에서 편집합니다. `Shockwave Color`, `Sorting Order`, `Visual Scale`은 보스에서 조절합니다.
- **Visual Scale은 그림과 실제 원형 타격 반지름을 함께 변경합니다.** 실제 반지름 = Radius × Visual Scale(최소 0.01). Radius 0.35, Scale 3이면 반지름 1.05이며 보스 선택 기즈모도 같은 값을 사용합니다. 플레이어/벽 충돌과 패링 후 귀환에도 이 크기를 사용합니다. 피해량·속도·사거리는 바뀌지 않습니다. 값 변경은 새로 발사하는 충격파부터 적용됩니다. 애니메이션 프레임별 투명 영역/형태를 따라 콜라이더가 변하는 방식은 아니며, 원형 판정과 그림 확대 배율을 연동합니다.
- 기존 ReflectProjectile을 재사용하므로 서로 충돌하지 않으며, 가드/패링/반사 오류 규칙이 적용됩니다. 패링 성공 시 발사자 쪽으로 튕겨 돌아가 보스에게 피해를 줄 수 있고 **패링 누적 횟수에도 포함**됩니다. 일반 벽에는 막히고, 반사 오류가 적용된 물체/표면에서는 한 번 반사할 수 있습니다.
- 방 이탈, 플레이어 즉사 프레임, 보스 사망/비활성화 시 해당 보스의 모든 충격파를 정리합니다. **N번째 패링 경직에서는 적대 충격파만 정리**하고 패링한 충격파는 보스에게 돌아갑니다. 충격파는 패링 시 귀환에 필요한 수명을 확보하며, 일반 몬스터 탄환의 수명은 변경하지 않습니다.

### 날아가는 충격파 이펙트 애니메이션 편집

1. Project의 `Assets/Resources/TutorialBossEffects/ShockwaveEffect.prefab`을 더블클릭해 Prefab Mode로 엽니다.
2. 루트 **ShockwaveEffect** 선택 → **Ctrl+6 → Shockwave_Fly** 클립을 선택합니다. 보스 동작용 Boss_Shockwave와는 다른 클립입니다.
3. **Sprite Renderer → Sprite** 트랙의 임시 키 두 개를 교체하여 원하는 스프라이트 프레임을 넣습니다. 현재는 기존 `Effect/shockwave-01.png`의 첫 Sprite를 임시로 넣었으며 나머지 프레임을 자동 삽입하지 않았습니다. Loop Time은 ON입니다.
4. 원본 이미지가 위로 진행하면 프리팹의 `BossShockwaveEffect → Sprite Forward Angle`은 90, 오른쪽이면 0을 사용합니다. 발사/표면 반사/패링 후 이동 방향에 맞춰 그림도 회전합니다.
5. `Tint On Parry / Parried Color`로 패링 성공 색상을 조절합니다. 기본은 청록색이며 같은 Fly 애니메이션을 계속 재생합니다. 색상/회전/Scale 키는 넣지 말고 Sprite 키만 사용하세요.

프리팹은 SpriteRenderer/Animator/ReflectProjectile/BossShockwaveEffect가 **한 루트에** 있습니다. 씬에 따로 배치하거나 Visual 자식을 만들 필요 없습니다. `Tools → Story → Tutorial Boss → Configure Shockwave Effect`는 없는 에셋만 준비하며 기존 프레임/프리팹을 덮어쓰지 않습니다. 원본 Effect 폴더의 이미지와 슬라이스는 그대로 보존합니다. 자동 슬라이스로 한 이미지가 여러 Sprite로 나뉜 경우 Animation 창에 넣기 전에 사용할 프레임 범위를 Sprite Editor에서 확인하세요.

### 충격파 공격 애니메이션 넣기

1. 보스 **루트 오브젝트**를 선택하고 Ctrl+6을 누릅니다.
2. `Boss_Shockwave` 클립을 선택해 **Sprite Renderer → Sprite** 트랙에 프레임을 넣으세요. 임시 키는 교체/삭제해도 됩니다. 별도 Body/Visual 자식은 만들지 않습니다.
3. Loop Time은 OFF로 두고, 발사할 프레임 번호를 보스의 `Shockwave Release Frame`에 맞춥니다. 근접 Slam Hit Frame과는 별개입니다.
4. `TutorialBoss.controller`에 **Shockwave** 상태가 연결되어 있습니다. 스크립트가 직접 재생하므로 별도 Trigger/전이 설정은 필요 없습니다. 자동 종료 전이는 만들지 마세요.

`Tools → Story → Tutorial Boss → Configure Shockwave Animation`으로 이 상태만 다시 연결할 수 있습니다. 기존 클립/상태 Motion은 덮어쓰지 않습니다. Animator/상태가 없는 기존 보스는 Windup Time 뒤 타이머로 발사합니다.

## 패링 누적 / 균형

- `Melee Parry Window`(기본 0.3초)는 이 보스 **근접 공격만** 완화하는 최소 패링 시간입니다. 타격 전 0.3초 안에 우클릭을 시작하고 맞는 순간까지 유지하세요. 일반 몬스터와 모든 투사체는 플레이어 기본값(현재 0.2초)을 유지합니다. 플레이어 기본값을 더 길게 설정한 경우 줄이지 않습니다.
- 현재 `Slam Windup Time` 0.9초 기준, 보스 공격 시작 후 약 0.6~0.9초에 입력하면 성공 범위입니다(게임 시간 기준). 공격/대시/편집 모드 등 가드 불가 상태는 성공하지 않으며, 한 입력으로 두 번 패링하지 않습니다. 이미 피해를 받은 뒤 입력해 소급 성공하는 방식은 아닙니다.
- Parries To Stagger: 필요 횟수 N, 기본 3. 근접 공격·낙석·충격파 패링을 함께 누적합니다.
- 패링할 때마다 플레이어 피해/가드 게이지 소모는 기존처럼 무효화됩니다. N회 미만이면 보스는 경직되지 않습니다.
- 낙석 패링도 같은 누적 횟수를 올립니다. 다른 원거리 몬스터의 투사체 동작은 변경하지 않습니다.
- N회가 되면 준비 중인 공격을 취소하고 Stagger Duration(2.5초) 동안 경직합니다. 경직 시작 시 누적 횟수를 0으로 초기화합니다. 경직 중 추가 패링은 다음 경직에 누적하지 않습니다.
- 누적 횟수는 시간에 따라 자동 감소하지 않습니다. 보스 경직/사망/비활성화 시 남은 낙석과 경고는 정리합니다.
- 머리 위에 HP와 패링 횟수/남은 균형 막대를 임시 표시합니다. Show Status로 끌 수 있습니다. 일반 적의 한 번 패링 경직은 그대로 유지합니다.

## 그림 교체

- 기본 이미지는 `golem-upper-left-128.png`입니다. 원본 PNG/슬라이스 설정은 변경하지 않습니다.
- `TutorialBoss` 하나에 SpriteRenderer, Animator, BoxCollider2D, Rigidbody2D, 보스 스크립트가 있습니다. 별도 `Body`나 `VisualRig`는 필요 없습니다. SpriteRenderer의 Sprite에서 그림을 교체하세요.
- 루트 Transform의 Scale을 바꾸면 그림과 Collider 크기가 함께 변합니다. 피격 범위만 바꾸려면 BoxCollider2D의 Size/Offset을 조절하세요. 이번 통합에서는 기존 화면상 크기와 월드 충돌 범위를 유지했습니다.
- `Rockfall Sprite`에 돌 이미지를 넣습니다. 비우면 사각 임시 그림입니다. 원거리 Projectile 설정은 제거했습니다.
- `Circle Sprite`는 낙석 경고 원, `Square Sprite`는 보스/낙석 이미지가 없을 때 쓰는 임시 그림입니다.
- `Slam Impact Sprite` / `Slam Impact Duration` 설정과 근접 이펙트 생성을 제거했습니다. 기존 이펙트 이미지 파일은 삭제하지 않습니다.
- **애니메이션 기준 근접 패링:** `Slam Hit Frame` 현재값은 **11**입니다. 해당 프레임에서 보스 `Melee Parry Window`(기본 0.3초)와 현재 가드 입력을 검사합니다. 너무 일찍 누르면 일반 가드이며, 타격 후 입력은 소급 적용하지 않습니다. 새 클립을 넣으면 실제 타격 동작에 프레임을 맞추세요. 현재 16프레임 클립의 이미지 GUID가 프로젝트 원본과 연결되지 않아 이번 패링 완화 작업에서는 타격 프레임을 임의 변경하지 않았습니다.
- `Slam Impact Delay`와 이펙트 후 0.15초 지연은 제거했습니다. 경직/사망/비활성화로 준비 중인 공격이 취소되면 타격도 취소됩니다. 일반 몬스터/투사체 패링은 그대로입니다.
- 기존 `Warning Opacity`와 `Slam Warning Parry Window`는 제거했습니다. 사용자 이펙트 이미지와 애니메이션 에셋은 유지합니다.
- 실제 동작 프레임은 각 클립의 Sprite 트랙에서 편집하세요. 이번 수정은 기존 Sprite 프레임, 컨트롤러, 프리팹과 씬 배치를 변경하지 않습니다.

## Animator / 애니메이션 편집

- `TutorialBoss.controller`의 Idle(대기), Move(이동), Slam(근접 휘두르기), Shockwave(충격파), Stagger(경직)을 사용합니다. 기존 Shoot 상태/클립은 사용자 프레임 보존을 위해 남겨 두지만 코드에서는 사용하지 않습니다. 낙석은 Animator 상태를 변경하지 않습니다.
- 씬의 **TutorialBoss**를 선택 → Ctrl+6 → `Boss_Idle / Boss_Move / Boss_Slam / Boss_Shockwave / Boss_Stagger`를 선택합니다. `Sprite Renderer → Sprite` 트랙에 애니메이션 프레임을 넣으세요.
- 애니메이션에는 Sprite 키만 사용하세요. 루트 Transform의 위치/크기/회전 키를 넣으면 Collider까지 움직입니다.
- `Slam Hit Frame`은 첫 프레임을 1로 세는 타격 프레임 번호입니다(지정은 2부터). Animation 창에서 실제 휘둘러 타격하는 프레임에 맞추세요. 클립 Samples에 따라 시간을 계산하므로 Samples/길이를 바꿔도 지정한 프레임을 따릅니다. 범위를 넘으면 마지막 프레임, 1프레임 클립이면 종료 시점을 사용합니다. Sprite 키 순번이 아니라 타임라인 프레임 번호입니다.
- `Shot Release Time`/`Shot Windup Time`은 더 이상 사용하지 않습니다. 낙석 시간표는 Rockfall 설정으로 조절하며 Animation Event는 필요 없습니다.
- `Slam Windup Time`(기본 0.9초)에 근접 타격 프레임에 도달하도록 재생 속도를 자동 조정합니다. 근접 전체 클립 길이는 후딜을 포함하므로 0.9초보다 깁니다. 후딜을 중간에 끊지 않습니다(경직/사망 제외). Animator State의 Speed는 양수로 두고 자동 종료 전환은 만들지 마세요.
- 패링 N회 경직은 진행 중인 공격을 취소하고 Stagger로 전환합니다. 경직 종료 후 Idle로 복귀합니다. 보스 Transform을 코드로 들어올리는 임시 연출도 제거했습니다.
- Animator가 없는 기존 오브젝트는 이전 타이머 방식으로 작동합니다. 재생 중 Animator를 끄면 진행 중인 공격을 안전하게 취소합니다.
- `Tools > Story > Tutorial Boss > Configure Animator`로 프리팹을 연결할 수 있습니다. 이전 Body/VisualRig 구조는 단일 루트로 통합하고, 루트 Transform 애니메이션 키는 제거합니다. 기존 Sprite 키와 상태 Motion, 에셋 GUID는 유지합니다. 사용자 컴포넌트나 추가 자식이 있으면 자동 제거하지 않고 중지합니다.

## 전투 구역 / 튜토리얼 연동

CombatAreaLock의 자동 수집이 켜져 있으면 구역 안 보스도 전멸 대상으로 포함됩니다. 또는 Enemies 목록에 보스 루트를 넣으세요. 죽으면 루트가 제거되어 벽 해제 조건에 반영됩니다. On Staggered / On Defeated 이벤트에 후속 연출을 연결할 수 있습니다. 기존 튜토리얼 단계는 자동 변경하지 않습니다.

## 패턴 랜덤 오류 / 패링 획득

- 충격파 그림 크기는 재생 중인 Sprite 프레임을 기준으로 실제 타격 지름에 맞춥니다. 프리팹의 임시 Sprite와 애니메이션 프레임 크기가 달라도 거대화 배율이 유지됩니다. 최대 가로/세로 길이 = `Shockwave Radius × Shockwave Visual Scale × 거대화 배율 × 2`이며 원본 가로세로 비율은 보존합니다. 애니메이션의 루트 Scale보다 이 크기 설정이 우선합니다. 패링으로 거대화가 제거되면 그림과 판정이 함께 정상화됩니다.

- `Enable Pattern Errors`를 켜면 **근접·낙석·충격파 시작마다** 거대화/가속/반사 중 활성화한 종류 하나를 균등 추첨합니다. `Pattern Error Chance`는 기본 1(매번), 0이면 일반 공격입니다.
- `Allow Giant / Acceleration / Reflection Pattern`으로 추첨 대상을 제한합니다. 테스트하려는 종류만 켜면 해당 오류만 나옵니다. 모두 끄면 일반 공격입니다.
- 거대화: 기본 1.5배. 근접은 보스 크기와 사각 타격 위치/범위가 함께 커집니다. 낙석은 돌·경고 원·착지 판정이 커지고 보스 크기는 그대로입니다. 충격파는 그림·실제 판정이 함께 커집니다. 커진 낙석 반지름을 기준으로 벽·방 경계·경고 겹침을 검사합니다.
- 가속: 기본 1.5배. 근접은 공격 애니메이션 재생 속도, 낙석은 실제 떨어지는 속도, 충격파는 이동 속도가 빨라집니다. 낙석의 경고 시간·돌 사이 시작 간격과 충격파 발사 준비 시간은 줄이지 않습니다. 패링하면 남은 효과가 정상화되며, 낙하 중인 돌의 현재 높이/진행률은 유지해 위로 되돌아가지 않습니다.
- 반사: 세 패턴 모두 **보스에게 피해를 준 플레이어에게 피해를 돌려주는 효과만** 적용합니다. `Pattern Reflection Multiplier` 기본 1=100%이며 플레이어 가드 감소는 기존 규칙을 따릅니다. 보스 자신도 원래 피해를 받습니다. 충격파의 일반 벽 반사 효과와 `Pattern Reflection Bounces` 설정은 제거했습니다. 환경 표면 자체의 반사 오류는 그대로입니다.
- `Pattern Reflection Duration`: 반사 추첨 시점부터 유지할 시간이며 기본 **5초**입니다. 게임 시간 기준으로 슬로모션/일시 정지를 따릅니다. 동작이나 낙석/충격파가 먼저 끝나도 남은 시간 동안 유지합니다. 반대로 시간이 먼저 끝나면 남은 공격에서 반사 오류도 제거되며, 만료 후 패링은 오류 보상을 지급하지 않습니다. 해당 회차 패링으로는 즉시 해제/획득합니다. 경직·방 이탈·대상 비활성화·보스 사망/비활성화 시 전부 해제합니다.
- 여러 반사 회차는 각각 시간을 셉니다. 겹쳐도 피해를 중복 반사하지 않고 가장 큰 배율 한 번만 적용합니다. 한 회차를 패링해도 다른 회차에 남은 반사가 있다면 유지됩니다. 머리 위에 적용 중인 반사의 남은 시간을 표시합니다.
- 낙석과 근접/충격파는 오류 회차를 따로 보관합니다. 한쪽의 시작/종료/패링이 다른 쪽의 거대화·가속을 덮어쓰지 않습니다. 머리 위 UI도 현재 동작 오류와 진행 중인 낙석 오류를 별도로 표시합니다.
- 머리 위 상태 UI에 현재 동작의 오류 이름을 표시합니다. 충격파는 거대화=주황, 가속=연두, 반사=보라 색으로 구분합니다. 동작이 끝나도 날아가는 충격파는 발사 때의 오류를 유지합니다.
- 오류 패턴을 패링하면 **그 공격 회차의 오류를 즉시 제거하고 보관함에 획득**합니다. 먹물을 쓰지 않으며 Cut 튜토리얼 성공으로 잘못 기록하지 않습니다. 발견 도감에도 등록합니다.
- 네 충격파는 한 공격 회차를 공유합니다. 하나를 패링하면 살아 있는 네 갈래의 오류가 함께 해제되고 보상은 한 번만 지급합니다. 이후 같은 회차를 패링해도 보상이 중복되지 않습니다. 다음 공격은 다시 새로 추첨합니다.
- 한 낙석 패턴의 돌들도 오류를 공유합니다. 하나를 패링하면 남은 돌의 크기/속도가 정상화되고 오류는 한 번만 지급합니다. 이후 다른 돌을 패링하면 횟수만 추가 누적됩니다. N번째 패링 경직에서는 남은 낙석을 모두 취소합니다.
- 이전 충격파를 패링해도 보스가 새로 준비 중인 다른 공격의 오류는 제거되지 않습니다. 패링 N회 경직은 기존처럼 별도로 누적됩니다. N번째 패링에서 튕겨 돌아가는 충격파는 유지합니다.
- 빈칸이 있으면 자동 저장합니다. 같은 종류를 이미 가지고 있으면 오류만 제거하고 중복 저장하지 않습니다.
- **보관함이 가득 차면 전투 중에도 교체 UI**를 표시합니다. 마우스 휠로 1/2번 슬롯 선택 → 좌클릭으로 기존 오류를 버리고 새 오류 획득. Esc는 획득만 포기하며 이미 제거한 보스 오류는 복구하지 않습니다.
- 교체 UI는 **기본 5초 뒤 자동 취소**됩니다. PlayerMove Inspector의 `보스 패링 보상 / 교체 UI > Boss Error Replacement Timeout`에서 시간을 바꿀 수 있습니다(최소 0.1초). 남은 시간을 UI에 표시하며, 휠 선택이나 같은 보상의 재수신으로 연장되지 않습니다. 시간 초과 시 새 오류 획득만 포기하고 기존 보관함은 유지합니다. 보스에서 제거한 오류는 복구하지 않습니다.
- 제한 시간은 게임 시간 기준으로 도감/일시 정지 중에는 멈춥니다. 교체 UI 자체는 시간 배율을 바꾸지 않습니다. 이동/가드/대시는 가능하고 교체 좌클릭이 공격/Cut/Paste로 전달되지 않습니다. 만료 시점의 좌클릭도 획득/공격으로 처리하지 않습니다. 교체 중에는 F/E/슬롯 사용을 잠시 막습니다. 즉사 재시작·플레이어 비활성화 시 미확정 보상 UI를 정리합니다.
- 새 partial 파일은 `Internal/TutorialBoss.PatternErrors.cs`, `Player/Internal/PlayerMove.BossErrorRewards.cs`입니다. **직접 컴포넌트를 붙일 필요가 없습니다.** 기존 프리팹/씬의 TutorialBoss와 PlayerMove에서 바로 동작합니다. 원본 스프라이트·애니메이터는 변경하지 않습니다.
